# The Beaufort Flock Files

A searchable evidence file on the Flock license-plate camera network in Bluffton, SC (Beaufort County). Ranked talking points, a plain-English timeline, the town's list of 50 camera sites, and follow-up FOIA requests. Every claim links to the public record it comes from.

**Live site:** https://drthunter.github.io/beaufort-flock-files/
